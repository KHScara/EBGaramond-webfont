# EBGaramond-webfont
A webfont version of EB Garamond that have every opentype function (not like Google Fonts' webfont version)

```
@font-face {
  font-family: "EB Garamond";
  font-display: swap;
  font-style: italic;
  src: url("https://cdn.jsdelivr.net/gh/khscara/EBGaramond-VariableFont_wght.woff2") format("woff2");
}

@font-face {
  font-family: "EB Garamond";
  font-display: swap;
  font-style: italic;
  src: url("https://cdn.jsdelivr.net/gh/khscara/EBGaramond-Italic-VariableFont_wght.woff2") format("woff2");
}
```
